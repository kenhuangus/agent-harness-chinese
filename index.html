CORE THESIS

大师课核心论点：传统软件工程 vs. 智能体驾驭工程

从确定性逻辑编码走向非确定性智能体控制 —— 为什么外部 Harness 框架才是最终的系统控制中枢？

🏛️

传统软件工程 (Traditional SE)

为确定性 IT 系统设计。通过 SDLC、Agile、DevOps、CI/CD、架构模式、测试金字塔与 SRE 体系，对明确编写的代码逻辑进行严格管控。核心特征是：相同输入必然产生确定、可重复的输出。

🛡️

智能体驾驭工程 (Harness Engineering)

为非确定性 Agentic AI 系统创立的全新工程学科。运行时行为是由底层模型、Prompt 上下文、记忆持久化、工具调用与多智能体编排共同概率性涌现的。核心使命是：在概率模型周围构建确定性控制环境，使智能体系统具备生产级可靠性、可观测性与安全性。

THE 5 PILLARS

核心驾驭架构五大支柱 (Core Harness Stack)

生产级 AI 编码智能体的工业级底层脚手架，构建无法突破的刚性控制边界。

🧠

1. 分层记忆系统

CLAUDE.md / AGENTS.md 规范文件结合 Auto Memory (MEMORY.md)，实现多级作用域继承与上下文压缩持久化。

🔒

2. 受限工具沙箱

最小特权工具白名单结合 Path.is_relative_to() 路径穿越防御，将写入严格锁定在工作区内。

🪝

3. 确定性钩子

Claude Code 31 个生命周期事件，通过 PreToolUse 拦截危险命令，PostToolUse 执行 AST 语法与秘钥扫描。

📊

4. Token 预算管理

20/20/50/10 黄金预算分配策略与首尾保留压缩 (Head/Tail Compaction)，从根源防御上下文溢出与目标漂移。

📜

5. 结构化审计追踪

不可变追加式 events.jsonl 与 telemetry.jsonl 日志标准，提供全流程毫秒级可追溯审计。
